# branch（分支库）

本目录存放 interface-design-expert 的执行流程细则，每个步骤独立成文件夹（文件夹名＝流程名）。

## 主干

[`流程/`](流程/流程.md)：十一步创建/评审流程 + 一个横切节点（浏览器学习）。

## 两条独立路径

- **创建（本技能被调用时的主路径）**：初始化 → 问题解析 → 领域定位 → 知识检索 →
  取证探查 → 专家判断 → 评审清单 → 契约建议 → 输出交付 → 收尾 → 完成
- **修改（本技能自身演进）**：初始化 → 修改流程 → 完成项目修改
