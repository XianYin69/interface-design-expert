# 修改流程

## 目的

修改 interface-design-expert 本体（判据、清单、脚本、约束）时走的独立路径；
内容修改一律经 `tmp/` 镜像 + 自更新接口，禁止就地改写。

## 动作

1. **建镜像**：把待改文件复制到工作区 `tmp/`，原件不动。
2. **改镜像**：在镜像上编辑；判据变更须同时改 `asset/knowledge/` 与
   `asset/checklists/` 对应条目，保持一一对应。
3. **比对**：`self_update.py compare`（镜像 vs 本体）列出差异与影响面（哪些节点引用该文件）。
4. **审批**：`resistance/` 内约束变更须先过 [审查约束](../../../resistance/审查约束/审查约束.md)，
   禁止删除任何约束条目。
5. **释放**：`self_update.py release` 把镜像落回本体并删除 `tmp/` 副本。
6. **校验**：`python scripts/check_links.py --root . --strict-url` 必须 0 悬空；
   `python scripts/knowledge_index.py --all` 必须九叶齐、无缺失文件。
7. **记账**：`CHANGELOG.md` 加条目（版本、动机、变更面、验证结果）；git 走功能分支→dev→main。

## 输出

`完成项目修改`：差异摘要 + 校验结果 + 提交号。

## 边界

- 只改本技能目录；不得顺手改 `general-programming` 或其他技能。
- 新增知识叶＝拓扑变更，须先证明「可执行判据 + 权威出处 + 取证脚本」三件套齐备，
  否则并入相邻叶（九叶判定不可再拓扑）。
