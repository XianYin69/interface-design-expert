# 初始化

## 目的

确认调用方（SMS 主流程 / 编码技能）、待评审的契约对象与取证范围，载入九叶知识树。

## 动作

1. 读 [references/知识树/知识树.md](../../../references/知识树/知识树.md) 与
   [asset/knowledge_tree.json](../../../asset/knowledge_tree.json)，确认九叶条目文件齐备。
2. 判定输入形态：契约文件（openapi.yaml / *.proto / asyncapi.yaml / schema.json / GraphQL SDL）·
   代码片段（SDK/客户端门面）· 纯咨询（设计取舍问答）。
3. 探测工具可用性：`python -c "import sys;print(sys.version)"`；
   按需探测 `spectral`、`buf`、`oasdiff`、`protoc`、`grpcurl` 是否在 PATH。
4. 声明边界：只读评审为默认；任何写盘（改调用方契约）需显式授权且先 `--dry-run`。
5. 存档：`process_chain.py save --step 初始化`。

## 输出

`会话基线`：Python 版本、可用外部工具、输入形态、契约协议族（HTTP/gRPC/GraphQL/事件/库面/ABI）、授权范围。

## 降级

外部工具缺失 → 标记「静态评审模式」，结论只给规范判据与人工核查步骤，不给运行结果；
不得因缺工具而跳过取证探查节点，改用 `scripts/` 内置标准库探针。
