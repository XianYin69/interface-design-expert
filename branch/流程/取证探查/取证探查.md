# 取证探查

## 目的

用 `scripts/` 探针取得可复现证据；未运行的结论不得写「已验证」。

## 动作

| 探针 | 取什么证 | 命令 |
|---|---|---|
| contract_lint | 契约结构缺陷：无 description、缺 error 响应、缺分页、裸 200 语义 | `python scripts/contract_lint.py <契约文件>` |
| compat_probe | 新旧契约差异的兼容性分级（additive/breaking/unknown） | `python scripts/compat_probe.py --old a.yaml --new b.yaml` |
| naming_probe | 命名一致性（大小写风格混用、复数、同义异名、保留字） | `python scripts/naming_probe.py <契约文件>` |
| error_model_probe | 错误模型完备性（状态码族、problem+json、错误码枚举、重试语义） | `python scripts/error_model_probe.py <契约文件>` |
| codegen_probe | 可生成性与工具可用性（spectral/buf/oasdiff/protoc 在位与否、版本） | `python scripts/codegen_probe.py --spec <文件>` |

1. 探针输出统一为 JSON，落 `tmp/`（不写 skill 目录），供 `advice_compose.py` 汇总。
2. 外部工具在位时以工具输出为准，内置探针结果标 `fallback`；两者冲突须复核并记逻辑链。
3. 每条证据保留**命令原文**，交付里可复现。

## 输出

`证据集`：探针名 → 命中项（含文件/行/字段定位）+ 命令原文 + 工具版本。

## 降级

无契约文件（纯咨询）→ 只做规范条文判断，明确标注「无取证」；
Python 环境缺依赖 → 探针只用标准库，正则解析失败项标 `parse-skipped` 而非「通过」。
