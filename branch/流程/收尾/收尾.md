# 收尾

## 目的

落链、清临时产物、按 git 工作流提交，然后收口返回调度方。

## 动作

1. 结论落链：`chain append` 到 knowledge/logic 链（判据修正、兼容性结论、命名裁定）。
2. 悬空链接自检：`python scripts/check_links.py --root . --strict-url`，必须为 0。
3. 垃圾回收：`tmp/` 证据与 verdict 中间产物释放或删除，不随包交付、不写进 skill 目录。
4. 过程链存档：`process_chain.py save --step 收尾`；失败路径记 `interrupt` 后 resume。
5. Git 工作流（见 [git工作流约束](../../../resistance/git工作流约束/git工作流约束.md)）：
   本步提交到功能分支 `feature/<topic>` → 双链辩论与 check-links 通过合 `dev` →
   整体审查通过 `dev` 合 `main`；**推送前须用户确认**，未确认不得 `git push`。
6. 收口返回 SMS 主流程整合续排：本技能完成 ≠ 整段任务完成。

## 输出

`收尾报告`：链接数、tmp 清理结果、git 分支与提交号、链写入条目数。

## 降级

git 不可用 → 保留文件产物并如实报告「未提交」，不得伪造提交号；
check_links 非 0 → 先修链接再收口，重试达 10 次触发熔断回调用方。
