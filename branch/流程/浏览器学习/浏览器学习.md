# 浏览器学习（横切节点）

## 触发

任一步骤遇到下列情形，**强制**先学后答，不得凭记忆作答：

- 不确定的规范条款（OpenAPI 3.1 与 3.0 的 JSON Schema 对齐差异、AsyncAPI 3 的 channel 语义、
  proto3 field presence、RFC 9457 的 `type` 是否可为相对 URI）。
- 工具行为与版本差异（spectral 规则集、buf breaking 默认检查项、oasdiff 的破坏性分类）。
- 新出现或本技能知识树未覆盖的协议特性（HTTP 语义扩展、gRPC 重试策略字段、GraphQL 持久化查询）。

## 动作

1. 派 `file_ops`（`ff_lite.py search "<词>" [n]` / `fetch <url>`）检索，只传**意图 + 参数**，
   不内嵌其正文、不改其目录；须调用方已 `:grant network`。
2. 取到可达源后记录：URL、页面标题、确证日期；标题与所查条款一致才算确证。
3. 结论回填：能进判据的写 `asset/knowledge/<叶>.md`（走 update 审批流），
   属书目/规范出处的写 [参考书目](../../../references/参考书目/参考书目.md)。
4. 未确证一律标 `[本地]`，**不填 URL、不臆造**；缓存落工作区 `tmp/`，不入 skill 目录。
5. 学习完成后回原节点继续，不得停在浏览器学习。

## 输出

`确证条目`：条款 → 出处 URL/规范小节 → 确证日期 → 回填位置。

## 降级

无网络授权或源不可达 → 降级为 `[本地]` 判断并显式声明「未联网确证」，
涉及发布阻断的结论不得建立在未确证条款上。
