# 知识检索

## 目的

按定位结果取回判据与清单（＝经验查询节点在本技能被调用时的形态）。

## 动作

1. `scripts/knowledge_index.py --topic <叶 id>` 取该叶的判据条目、权威出处与配套清单路径。
2. `--all --format json` 取全树索引，用于跨叶合成时对齐术语（如 `idempotency-key` 拼写）。
3. 每条被引用的判据记下**出处键**（如 `RFC9457 §3`、`AIP-132`、`proto3 field number`），
   无出处的判据只能作建议，不得进 BLOCK 项。
4. 本地判据不足（新协议特性、工具版本行为）→ 触发
   [浏览器学习](../浏览器学习/浏览器学习.md)，确证后回填 `asset/knowledge/` 走 update 审批流。
5. 检索链上历史结论：`chain recall` 同叶既往判断，避免同一契约给出前后不一致的结论。

## 输出

`判据集`：叶 id → 条目列表（每条含出处键）+ 配套 BLOCK 清单路径。

## 降级

知识文件缺失或索引零命中 → 记中断（`process_chain.py interrupt`），降级为「仅规范条文判断」，
并在交付的「未覆盖」段声明缺失叶。
