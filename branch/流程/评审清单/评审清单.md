# 评审清单

## 目的

按叶逐条过 BLOCK 项，产出可核对的判定表，防止「整体感觉还行」式评审。

## 动作

1. `scripts/review_checklist.py --topic <叶 id> --format json` 取清单条目（`BLOCK` 前缀＝阻塞项）。
2. 每条给三态：`pass` / `fail` / `n-a`（不适用须写理由，不得留空）。
3. 任一 `fail` 的 BLOCK 项 → 必须出现在交付的「阻塞项」段，并给出**最小修复**（改哪个字段/哪一行）。
4. 跨叶去重：同一缺陷在多叶重复命中时只保留最高优先级一条，其余标 `dup-of`。
5. 清单条目本身不适用于该协议族（如 GraphQL 无 HTTP 状态码语义）→ 标 `n-a` 并指向该族的等价条款。

## 输出

`判定表`：叶 → 条目 → 三态 + 证据引用 + 最小修复。

## 降级

清单文件缺失 → 记中断并回 [知识检索](../知识检索/知识检索.md)；
临时评审（调用方只要 5 分钟结论）→ 只跑 BLOCK 项，advisory 项在「未覆盖」段声明未查。
