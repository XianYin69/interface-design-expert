# 领域定位

## 目的

把问题卡映射到九叶知识树的**一个或多个**叶子，允许多标签并行检索后在专家判断处合并。

## 动作

1. 跑 `scripts/classify_topic.py --text "<问题卡>" --spec <契约文件> --top 3`，取主叶与次叶。
2. 常见合成域（必须同时取，不得只取一叶）：
   - 演进期改动 → `versioning-compatibility` × 被改动的语义叶（如 `error-model`）。
   - 列表端点 → `pagination-filtering-sorting` × `http-rest-semantics` × `schema-contracts`。
   - 异步消息 → `schema-contracts` × `reliability` × `observability-contract`。
   - 公开 API → `security-authn-authz` × `naming-docs-tooling` × `error-model`。
3. 标签冲突（同一改动既属版本兼容又属安全）→ 以「破坏性 × 暴露面」二维矩阵定优先级，
   记入逻辑链（`logic_chain.py add`）。
4. 落不到任何叶 → 触发 [浏览器学习](../浏览器学习/浏览器学习.md)，确证后再决定是否属转派项。

## 输出

`定位结果`：主叶、次叶、合成理由、转派项。

## 降级

分类脚本零命中 → 按问题卡关键词人工映射，并在结论里标注「分类未命中，人工定位」。
