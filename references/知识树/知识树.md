# 知识树（接口设计专家领域）

根：软件接口与 API 契约的设计判断。拓扑规则：每个叶子必须同时给出
**可执行判据 + 权威出处 + 取证脚本**；若某主题无法同时满足三者，则并入相邻叶子，不新开叶。

当前九叶覆盖「传输语义 → 契约表达 → 演进 → 失败语义 → 集合语义 → 信任边界 →
失败恢复 → 运行可见性 → 工程化」，再细分只会产生同一判据的别名（如「HTTP 缓存」属
`http-rest-semantics` 的条件请求条款、「限流」属 `security-authn-authz` 的配额条款），
故判定为**不可再拓扑**。

## 跨叶合成

演进 × 语义（改字段先问破坏性）、错误 × 可靠性（重试语义由错误类别决定）、
契约 × 工具链（schema 表达力决定 codegen 质量）为常见合成域，由
[领域定位](../../branch/流程/领域定位/领域定位.md) 允许多标签并行检索后在
[专家判断](../../branch/流程/专家判断/专家判断.md) 合并。
