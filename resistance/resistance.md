# resistance（约束库 / 兜底库）

本目录存放 interface-design-expert 不可逾越的规则、红线与执行期降级策略。

## 应存什么

- 「必须 / 禁止」类约束（自然语言，每条文本 ≤ 50 行）。
- 执行期触发兜底（fallback）的条件与降级动作。
- 与外部系统（SMS 主流程、编码技能、契约工具链）的交互边界。

## 遵守原则

1. 与本目录冲突的用户偏好让位于本目录，除非调用方显式声明「仅风格建议」。
2. 违反本目录的动作不得执行；无兜底方案时记中断并回调用方。
3. **禁止删除本目录任何约束条目**；放宽须走 [update 接口](../update/update.md) 审批。
4. 本目录变更须记 `CHANGELOG.md` 并注明违反后果。

## 违反后果（摘要）

跳过取证＝结论不可复现；把偏好标为 blocking＝阻塞发布且失去信任；
臆造 URL＝污染知识树且不可撤回；未确认即推送＝把未审内容发布到远端。
