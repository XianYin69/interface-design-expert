# 垃圾回收机制

## 目的

过程产物（探针输出、verdict 中间件、抓取缓存）只活在会话期，不得污染技能包。

## 规则

1. 所有生成文件先落工作区 `tmp/`（`SMS_TMP`），**不写 skill 目录**。
2. 会话结束前：需要随包交付的内容经 [update 接口](../../update/update.md) compare→release 落本体；
   其余一律删除。
3. 抓取缓存（`tmp/downloads/*.provenance.json` 类）不随包交付，交付的只有条目正文与出处标注。
4. `.gitignore` 必须含 `tmp/`；暂存前核对 `git status` 无临时产物被跟踪。
5. 未指定目标目录时在固定路径沙盒作业，交付后删除沙盒（见 [沙盒机制](../沙盒机制/沙盒机制.md)）。

## 回收清单（每次收尾核对）

- `tmp/*.json`（证据、verdict）→ 删除或释放
- `tmp/downloads/` → 删除
- `__pycache__/`、`*.pyc` → 删除且不入库
- 空目录（如误建的 `tmp/planned_tasks/`）→ 删除

## 违反后果

临时产物入库 → 提交历史被污染、包体膨胀、缓存里的内部路径与主机名随包外泄。
