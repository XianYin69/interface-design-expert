# 浏览器学习约束

## 必须

1. 遇到不明确的规范条款、字段语义、工具行为，**先学后答**：派 `file_ops`
   （`ff_lite.py search` / `fetch`）检索，取到可达源后再下结论。
2. 确证标准：返回页面标题与所引规范名一致；重定向后以**落地仓库**为 `source_url`。
3. 每条 `[联网]` 条目必须记：URL + 规范名 + 确证日期 + 回填位置。
4. 涉及发布阻断（blocking）的结论，其条款依据必须已确证；未确证只能给 advisory。
5. 学习完成后回原节点继续，不得停在浏览器学习。

## 禁止

- 禁止凭记忆臆造 API、字段名、状态码语义、规范小节号。
- 禁止臆造 URL；禁止把搜索引擎摘要当作规范原文引用。
- 禁止未确证条目标 `[联网]`；未确证一律 `[本地]` 且不填 URL。
- 禁止把抓取缓存、中间产物写入 skill 目录（一律工作区 `tmp/`）。
- 禁止在本技能内直接发网络请求——联网动作只经 `file_ops`，且须调用方已 `:grant network`。

## 降级

无网络授权 / 源不可达 → 标 `[本地]` 并在交付「未覆盖」段声明「未联网确证」；
若该结论属 blocking，则降为 advisory 并要求调用方自行核对规范原文。

## 违反后果

臆造出处 → 知识树被污染，后续所有评审引用错误判据，扩散不可撤回。
