# 过程链存取

## 目的

流程可中断、可恢复：任一步失败或信息不足时记录中断点，补齐后 resume 回原节点，
不得从头重跑或跳步。

## 规则

1. 每个节点完成即存档：`process_chain.py save --step <节点名>`（步骤名＝文件夹名）。
2. 失败/缺信息 → `process_chain.py interrupt --step <节点> --reason <原因>`，
   然后回调用方索取缺失项（如旧版契约、客户端清单）。
3. 补齐后 `process_chain.py resume` 返回中断节点继续，**不得跳过中间节点**。
4. 中断记录必须含：所在叶、缺失项、已取得的证据、下一步动作。
5. 过程链存档落用户缓存目录；`tmp/` 里的证据文件按 [垃圾回收机制](../垃圾回收机制/垃圾回收机制.md) 处理。

## 常见中断场景

| 场景 | 缺失项 | 恢复条件 |
|---|---|---|
| 演进期只给新版契约 | 旧版契约 | 取得旧版后回 [取证探查](../../branch/流程/取证探查/取证探查.md) |
| 破坏性判定依赖客户端行为 | 客户端反序列化配置 | 取得配置或补契约测试后回 [专家判断](../../branch/流程/专家判断/专家判断.md) |
| 条款未确证 | 网络授权或可达源 | 确证后回 [浏览器学习](../../branch/流程/浏览器学习/浏览器学习.md) |

## 违反后果

跳步 → 结论缺证据链，调用方无法复现；不记中断 → 同一缺失项反复索取。
